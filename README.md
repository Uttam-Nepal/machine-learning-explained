# Machine Learning Explained

Code for the whiteboard videos on machine learning. Every folder matches one video and has a Google Colab notebook. No installs needed: open it in Colab and press **Shift + Enter** on each cell.

| Video | Notebook |
|---|---|
| What is Machine Learning? | [what_is_machine_learning.ipynb](what-is-machine-learning/what_is_machine_learning.ipynb) |
| Python for Machine Learning | [python_for_machine_learning.ipynb](python-for-machine-learning/python_for_machine_learning.ipynb) |

## How to run a notebook in Google Colab
1. Open the notebook file above on GitHub.
2. Change `github.com` in the address bar to `githubtocolab.com` and press Enter, **or** go to [colab.research.google.com](https://colab.research.google.com), choose **GitHub**, and paste this repo's link.
3. Run each cell from top to bottom.
