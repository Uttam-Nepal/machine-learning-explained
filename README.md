## How to use a notebook
1. Click **Open in Colab** next to the video. Sign in with a free Google account if asked.
2. Click **File → Save a copy in Drive** to get your own copy you can change.
3. If Colab warns that the notebook was not authored by Google, click **Run anyway** (normal for shared notebooks).
4. Run each cell from top to bottom with **Shift + Enter**.
